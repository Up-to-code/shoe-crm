# Shoe crm

تطبيق متكامل لإدارة علاقات العملاء في مجال العقارات، يوفر أدوات متقدمة لتحسين تجربة العملاء وزيادة المبيعات.

[Source](https://github.com/Up-to-code/shoe-crm) · [Issues](https://github.com/Up-to-code/shoe-crm/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/shoe-crm.git
cd shoe-crm
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run start` | Start the configured application |
| `npm run build` | Build the project |
| `npm run lint` | Check lint rules |
